# V2X Reliability Simulation

## Description
This project simulates a Vehicle-to-Vehicle (V2V) communication system and evaluates its reliability under packet loss and latency constraints.It aims to study the impact of communication failures on intelligent transport systems.

## Objectives
- Analyze the impact of communication failures on vehicle safety
- Study packet loss and latency effects
- Explore resilience mechanisms in V2X systems

## Technologies
- Python
- Simulation modeling

## Scenario
Vehicles communicate braking events. If communication fails, collisions may occur.

## Output
- Number of collisions
- Impact of packet loss on safety

## Relevance
This project is aligned with research topics in:
- Intelligent Transport Systems (ITS)
- V2X communications
- Reliability and resilience of wireless systems
